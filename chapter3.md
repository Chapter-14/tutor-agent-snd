## Page 3

**Definitions**

*   **Capital Budgeting:** The process of evaluating and selecting long-term investments that are consistent with the firm's goal of maximizing owner's wealth.
*   **Capital Expenditure:** An outlay of funds by the firm that is expected to produce benefits over a period of time greater than 1 year.
*   **Operating Expenditure:** An outlay of funds by the firm resulting in benefits received within 1 year.

**Capital Budgeting Process**

It involves 5 distinct but interrelated steps in the process of capital budgeting:

*   Proposal generation (building an idea)
*   Review and Analysis (Calculations)
*   Decision making (Selecting)
*   Implementation (Execution)
*   Follow-up (Monitoring)

## Page 5

**Key Concepts**

*   **Projects**
    *   **Independent Projects:** Projects that are not part of or dependent on any other project and whose cash-flows are unrelated and independent of each other.
    *   **Mutually exclusive Projects:** Projects that compete directly with each other, only one is selected. *For example, if a manager has a choice to make between undertaking projects X and Y, and must choose either of the two and not both, then projects X and Y are said to be mutually exclusive.*
*   **Funds**
    *   **Unlimited Funds:** A financial situation in which firm is able to accept all proposed projects that give acceptable return.
    *   **Capital Rationing:** A financial situation in which firm is not able to accept all proposed projects that give acceptable return and hence selects the best project or projects.
*   **Procedures**
    *   **Accept-Reject Criteria:** Rules to accept or a reject project depending on rate of return at acceptance level.
    *   **Ranking of Projects:** The projects are ranked depending upon the returns they generate.
    *   **Cash flow Types:** Single amount (one cash flow), an annuity (same value each time), or a mixed stream (different values each time).

## Page 8

**Payback period (PBP)**

It is the amount of time required for a firm to recover its initial investment in a project in the form of cash inflows.

The criteria for acceptance and rejection of an investment option is determined in the following way:

1.  Accept project if its PBP is less than the minimum PBP.
2.  Reject a project if its PBP is more than the minimum PBP.

**Numerical:** The formula for payback period:

```
       Initial Investment
PBP = -----------------------
       Annual Cash Flow
```

## Page 17

**Net Present Value (NPV)**

It is a capital budgeting technique in which projects initial investment is subtracted from the present value of its cash inflows discounted at a rate equal to the firms cost of capital.

```
          n     CFt
NPV =   ∑    --------  – CFo
        i=1   (1 + r)^t
```

Where:
*   **CFt** is every year cash inflow.
*   **CFo** is cash outflow (initial investment)
*   **r** is the discount rate
*   **NPV** is the Net Present Value
*   **n** is the number of years.
*   **t** is the time period

---

## Page 18

**Criteria for NPV**

1.  If the NPV is greater than 0 US$ / SAR / Pound / Euro, then the project should be accepted.
2.  If the NPV is less than 0 US$ / SAR / Pound / Euro, then the project should be rejected.

## Page 20

**Solution 1**

| Year | Cash Inflow | Discount Factor 10% | PV Value (C2 × C3) |
| :--- | :--- | :--- | :--- |
| 1 | 15,000 | 0.909 | 13,635 |
| 2 | 20,000 | 0.826 | 16,520 |
| 3 | 55,000 | 0.751 | 41,305 |
| 4 | 75,000 | 0.683 | 51,225 |
| 5 | 85,000 | 0.621 | 52,785 |
| **Total Present Value (TPV)** | | | **175,470** |

**Calculate the discount factor for each year:** 1 / (1 + r)^n

*   1/ (1 + 0.10)^1 = 0.909
*   1/ (1 + 0.10)^2 = 0.826
*   1/ (1 + 0.10)^3 = 0.751
*   1/ (1 + 0.10)^4 = 0.683
*   1/ (1 + 0.10)^5 = 0.621

**Net Present Value = Total PV – Initial Investment**
= 175,470 – 100,000 = **75,470**.

**Since the NPV (75,470) is positive we accept the project.** NPV is greater than Zero, we accept the project.

**Internal Rate of Return (IRR)**

It is a sophisticated capital budgeting Technique, a discount rate that equates the NPV of an investment opportunity with US$’0’ (zero). As present value of cash inflow is equal to initial investment.

```
          n     CFt
        ∑    --------  = CFo
        t=1   (1 + IRR)^t
```

Where:
*   **CFt** is every cash inflow.
*   **CFo** is cash outflow (initial investment)
*   **IRR** is the Internal Rate of Return
*   **n** is the number of years.
*   **t** is the time period

---

## Page 27

**Decision Criteria in IRR**

1.  If IRR is greater than cost of capital accept the project.
2.  If IRR is less than cost of capital reject the project.

**Solution 1**

```
       Annual Cash inflow
```

**Step 2:** Locate the present value interest factor of the annuity (PVIFA (Table 4)) that is closest to (PBP above) in the period of the max cash inflows years. See PVIFA table attached.

PVIFA closest to **5** in the **6th** period row

---

## Page 31

**Solution 1**

**Step 3:** Find IRR

```
                            LR PVA value – PBP value
IRR = Lower Rate (LR) + --------------------------------
                            LR PVA value - HR PVA value
```

*   LR is lower rate = 5%
*   LR PVA value = 5.076
*   PBP Value = 5.00
*   HR (higher rate) PVA Value = 4.917

```
                  (5.076 – 5.00)          0.076
IRR = 5% + ---------------------- = 5% + -------
                  (5.076 – 4.917)         0.159
```

**= 5 + 0.47 = 5.47 %**

Since the calculated IRR (5.47%) is less than the required cost of capital (IRR) of 9%, we **reject the project** proposed to Ahmed.
